# 文章缩略图预览

[English](README.en.md) | 简体中文

Chrome / Edge Manifest V3 扩展，在支持的 Discuz! 论坛列表页显示帖子图片缩略图，并汇总可复制的资源链接。

当前版本：**1.18.5**。无需服务器、npm 安装或构建即可使用。

1.18.5 新增资源标记：在列表页给帖子点「标记」，保存标题、链接、提取码和解压密码，之后在扩展弹窗导出成 TXT；每次导出或复制都会按日期自动备份。同时修复了提取码可能配到相邻链接上的问题。

1.18.4 起“立即重置论坛节流”在任何页面打开弹窗都能用，一次重置所有论坛域名。

1.18.3 在弹窗“维护”中新增“立即重置论坛节流”，并显示当前论坛标签页的节流速度：触发论坛验证页后扩展会自动放慢并记住 24 小时，现在可以一键恢复正常速度。

1.18.2 让首屏按正在看的内容加载：论坛请求名额优先给屏幕内的帖子，翻页和滚动后屏幕内的帖子几乎立即出现，不再自上而下每 2 秒出一帖；附件图床轮换到坏掉的域名时，改用本页正常的同族图床。

1.18.1 让动图下载通道按图床实际速度自适应，屏幕内的图片加载更快；动图缩略图默认显示静帧、悬停播放，减少滚动卡顿。

1.18.0 支持论坛镜像/反代站点：在弹窗“镜像站点”中逐个授权后即可在该域名运行，镜像页只读取本站内容。修复论坛验证页 / 限流页被当作空帖、导致每页最后几帖长期无图的问题，发往论坛的请求改为统一节流并在限流时暂停重试；动图单独限流（每个图床同时最多 2 张）并放宽截止时间，首屏先加载静态图，避免几 MB 的动图占满带宽、拖垮同屏缩略图；减少离屏帖子预载、加载中缩略图的微光动画、后台重试扫描和畸形内容解析造成的卡顿，并修正调度、TXT、缓存与日志多处缺陷。

1.17.8 将屏外和滚动后的后台图片任务按帖分批入队，避免长列表一次性创建数百个待视口任务，降低调度扫描和内存压力。

1.17.7 将“屏外首批自动加载”恢复为默认关闭。旧版保存的默认开启值不会沿用；如需全页预载，可在设置中手动开启。长列表默认回到按视距抓取和加载，优先保证滚动响应。

1.17.6 限制全页自动加载时单个普通图床最多 6 张在途图片；慢图在首次超时后保留原请求直到单图总截止时间，避免中断依赖 Referer 的请求并立即重试。真实图床速度仍受网络与站点限制。

1.17.5 将屏外首批普通图片限制在最多 3 路，并在页面滚动期间暂停启动新的屏外请求，减少长列表同时抓取和解码原图造成的卡顿；可见图片仍优先，帖内首批数量不变。

1.17.4 修复文章视图缓存键与 TXT 附件误识别；屏外帖子可按每行列数 × 可见行数逐步加载首批图片，并保留可见区域优先和并发限制。诊断日志减少重复存储，保留裁剪范围、有效设置与首末异常，导出前刷新当前标签页缓冲日志。

1.17.3 优化调度顺序：空槽先交给已登记的真实可见图片，再处理普通队列，避免仅靠异步唤醒时被预取任务抢先占用。调试统计复用未变化的后台队列快照，减少长队列重复扫描；不改并发、图片上限或用户设置。

1.17.2 修复插件加载槽与浏览器原生懒加载冲突：已经取得槽位并开始超时计时的图片使用 eager 发起请求，屏幕外仍保持 low 网络优先级，避免尚未请求就超时并误触发图床降载。未获槽位的图片继续按需等待，并发、用户参数和缓存格式不变。

1.17.1 修复工具栏原生弹窗无操作时持续闪动：文档使用稳定的 320px 宽度，避免视口宽度与自动尺寸形成反馈循环。新增原生 action popup 连续尺寸采样回归；图片调度和用户参数未改动。

1.17.0 增加 TXT 等待队列背压、持续集成及页面结构夹具。图片并发、缓存格式和权限不变。

1.16.11 保留图片 URL 查询参数中的合法 ASCII 标点，修复 DOM 与回退提取链重复解码；图片与 OG 标签改为有界顺序扫描，避免异常标签卡顿。浏览器测试的调试命令和 HTTP 请求增加独立超时及等待状态清理。

1.16.10 修复实体重复解码、特殊密码丢失及 HTML 标签识别边界，并将大量注释的预处理改为单次顺序扫描。TXT 页面桥接在请求层限制同源重定向，拒绝响应时及时取消未读取的数据流；图片并发与用户设置不变。

## 安装与启动

1. 下载并解压安装 ZIP，或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的目录：仓库根目录、安装 ZIP 解压目录，或打包生成的 `dist/chrome-unpacked`。
5. 如已安装另一份旧版，先禁用旧版，避免重复注入。刷新论坛列表页，通过工具栏扩展图标或页面右下角浮窗调整设置。

不要双击 `popup.html`，它依赖浏览器扩展环境。加载后请保留安装目录；更新文件后，在扩展管理页点击重新加载，再刷新论坛页面。

## 功能

- 列表页缩略图、点击大图预览、可视区域优先调度。可选开启屏外首批自动加载：每帖自动加载每行列数 × 可见行数，更多图片在展开或滚动帖内缩略图区后加载。
- 普通图片和重图独立并发、图床退避、解码预算及隐藏标签页暂停。
- 提取 ED2K、磁力、百度网盘、夸克、115、阿里云盘、UC、迅雷云盘和部分普通文件链接。
- TXT 附件自动低并发解析；失败时可手动重试或导入已经下载的 TXT。
- 本地配置、缓存和诊断日志；支持清理与参数调整，详细 DEBUG 日志默认关闭。

诊断日志即使关闭 DEBUG 也会记录精简的最终图片失败信息。每个页面会话保留有效加载参数、首次和最近异常、图床异常计数及明细裁剪范围；导出前会请求当前论坛标签页写入缓冲日志。导出内容会去除链接查询参数，但分享前仍请检查路径和帖子信息。

## 支持范围与隐私

内置支持 HTTPS 的 `sehuatang.org`、`sehuatang.net` 及其子域名；附件跨域请求另允许下载中转域名 `dl.ldkms.la` 和 `xia.ewrewej.la`。

### 镜像 / 反代站点

论坛的其他镜像或反向代理域名可在弹窗“镜像站点”中添加：在该站点页面打开弹窗并点击“添加当前站点”，或输入域名（如 `mirror.example`）后点击“添加”。浏览器会弹出授权框，确认后扩展才会在该域名及其子域名运行；添加当前站点时会自动刷新该页，其他已打开的页面需手动刷新。

- 仅支持 HTTPS；IP、本机地址、内置域名和下载中转域名不能添加；最多 20 个。
- 每个镜像是独立站点：镜像页只抓取、解析和读取同一镜像的帖子、附件和缓存，不会用内置论坛或其他镜像的登录会话抓取内容。内置两个域名之间保持原有行为。
- 移除镜像会撤销浏览器授权并注销脚本，已打开的页面刷新后停用；也可以在扩展管理页的“网站访问权限”中管理。
- 权限说明：`scripting` 用于为已授权镜像注册内容脚本；`activeTab` 让弹窗读取当前标签页地址以便一键添加；可选主机权限 `https://*/*` 只是上限，安装时不授予任何网站，必须逐站点确认。

扩展申请 `storage`、`scripting`、`activeTab` 和上述站点访问权限，没有自建上传服务器。论坛正文、附件和图片请求仍会连接相应网站；同源附件读取可能使用当前论坛会话。本地缓存和日志可能包含浏览痕迹，分享问题报告前请检查导出内容，不要上传浏览器资料、Cookie 或私人附件。

## 开发与验证

验证使用 Node.js，当前验证环境为 Node.js 22。没有第三方 npm 依赖。在仓库根目录运行：

```powershell
node tools/verify.js
```

该命令检查 JS 语法、Manifest 引用与权限、文档版本、沙箱行为回归，并运行七组独立测试。测试专用内部入口仅注入沙箱，不加入生产扩展。

Windows 下打包（需要 PowerShell 和 Node.js）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-extension.ps1 -WhatIf
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-extension.ps1 -Zip
```

输出位于 `dist/`，包括 `chrome-unpacked`、安装 ZIP 和 SHA-256。脚本仅复制 Manifest / popup 引用的运行时白名单，并复验实际目录及 ZIP；不会把文档、测试、日志和环境文件放入安装包。

打包后运行浏览器回归：

```powershell
node tools/browser-smoke.js
```

脚本使用独立临时浏览器资料及本地 HTTPS 合成论坛，不访问真实论坛。默认寻找本机 Playwright Chromium；也可显式指定支持自动加载扩展的 Chromium / Edge：

```powershell
$env:ATP_BROWSER_PATH = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
node tools/browser-smoke.js
```

它不需要安装 Playwright npm 包；浏览器可执行文件需自行准备。品牌版 Chrome 可能不接受自动化扩展加载参数，遇到此情况请使用 Chromium / Edge，或手动安装验证。

维护者完整交接包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-maintainer-handoff.ps1
```

## 常见问题

### TXT 背压

后台 TXT 仍最多同时处理 2 个任务；等待队列最多 32 个，每个标签页最多占 4 个等待位。队列等待上限为 30 秒或调用方截止时间（取较早者），不限制已经开始的任务至 30 秒。拥挤或过期返回可重试的未解析状态，不写永久失败缓存；稍后使用原有“解析TXT”入口重试。排队定时器和过期条目会主动清理。

### 持续集成与页面回归

GitHub Actions 在 push、pull request 和手动触发时运行 Windows / Node.js 22 验证、两类打包和固定 Playwright 1.63.0 Chromium 浏览器回归。作业最多运行 15 分钟，同一分支新推送取消旧任务；全部通过后保存安装 ZIP 与校验文件 14 天。工作流只读仓库权限，第三方 Action 固定到提交 SHA，不自动发布或修改代码。

新增列表页、图文帖、纯资源帖和登录拦截页四个结构案例。**它们是合成夹具，不是真实帖子快照**；详情见 [夹具说明与脱敏流程](tests/fixtures/pages/README.md)。原始页面只放在被忽略的 `.local-fixtures/`，不要直接上传。

### 统一验收建议

更新并重新加载扩展后，依次测试普通/重图混合列表、长列表滚动、多个标签页同时解析 TXT、忙碌后手动重试、切换后台及前进后退恢复。观察图片是否持续推进、TXT 是否最终可复制、是否出现重复浮窗。反馈时附版本、浏览器版本、复现步骤及检查过隐私的日志即可，不要附 Cookie 或完整登录页面。

### 故障排查

- **页面没有缩略图**：确认使用支持的域名（镜像站点需先在弹窗“镜像站点”中授权）、当前页面是帖子列表、扩展和当前站点开关已启用；重新加载扩展后刷新页面。
- **每页最后几帖暂时无图 / 标题后显示“论坛限流”**：论坛在几秒内收到约 30 个请求后会返回验证页。扩展发往论坛的请求最多连续 10 个，之后每 2 秒 1 个，屏幕内帖子优先，同一论坛的所有标签页共用这一额度；触发过验证页后，24 小时内不会再恢复到触发时的速度。若仍触发，会暂停 20 秒起（逐次翻倍，最长 5 分钟），之后逐个探测、自动重试；日志出现“论坛限流，暂停论坛请求”或“正文返回非帖子页”。验证页一般在浏览器正常打开论坛页面后解除，刷新列表页即可立即重试。扩展不会执行或应答验证页。
- **部分图片失败**：可能是图床失效、限流、登录限制或网络问题。降低并发后重试，必要时临时开启调试日志。
- **TXT 无法读取**：先确认浏览器能正常打开附件，再用手动重试或“导入已下载TXT”。扩展不保证受登录、挑战页或下载限制保护的附件可自动读取。
- **升级后出现两套浮窗**：检查是否同时启用了多个安装目录的扩展副本。

## 仓库结构与版本来源

- 根目录 JS / CSS / HTML、`manifest.json`、`icons/`：可直接加载的扩展。
